# 3.0.1 隐私填写依据

2026-10-19。与已发布的 3.0 相比，没有新增数据收集类别、追踪或第三方 SDK。仍由用户主动开启共享或直播，本机比赛不会因为升级自动上传。

沿用 3.0 的五类 App 功能数据：姓名、其他用户内容、用户 ID、设备 ID、产品交互。均与成员／设备关联，不用于追踪、广告或营销分析。具体范围为球员姓名和背号、球队和比赛、成员与设备标识，以及邀请、交接、角色管理等操作记录。

固定邀请链接包含用于加入球队的秘密，只按原有邀请流程使用，不随普通球队档案公开导出。服务器数据库与备份继续按私有数据保护。固定邀请不增加新的数据收集类别。

App 隐私问卷应继续反映整款 App 的实际行为；如 3.0 已按上述五类填写，3.0.1 沿用。不可因本次仅修复问题而改填“不收集数据”。没有替用户修改 App Store Connect。
