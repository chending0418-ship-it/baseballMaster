# 网站管理后台

2026-10-13 已部署：[https://baseballmaster.cc/admin/](https://baseballmaster.cc/admin/)。输入用户指定的后台密码即可登录，不需要账号或 App 设备授权。

这是网站总后台，与 App 内的球队管理独立。登录后可查看、下载所有球队、云端比赛和有效直播；不需要先加入球队，不受队内管理员／记录员／成员角色限制，也不占用每队最多两名管理员的名额。

## 查看和下载

| 页面 | 可查看内容 | 下载入口 |
| --- | --- | --- |
| 总览 | 有效球队数、云端比赛数、正在直播的数量、比赛正文与展示资料大小 | 下载全部云端资料（ZIP） |
| 球队资料 | 球队名称、球员中英文名和背号、成员称呼与角色、有效设备数 | 下载球队资料（ZIP） |
| 云端比赛 | 按球队或对阵搜索；筛选进行中、已结束、待开赛、已删除；查看比分、双方名单、统计和文字记录 | 比赛内容页下载 JSON |
| 实时直播 | 共享球队直播和原临时直播；区分正在进行与已终场但链接仍有效 | 直播内容页下载 JSON |

按球队查看比赛：打开「球队资料」，选择球队，点击「查看这支球队的比赛」。直播列表每 15 秒刷新；详情页点击「刷新资料」读取最新内容。

全部云端 ZIP 按 `teams/<球队编号>/` 分目录；单支球队 ZIP 直接包含 `team.json`、`members.json`、`matches/`、`manifest.json` 与说明文件。比赛文件保留完整云端正文和展示统计，清单含每个文件的 SHA-256 校验值。

临时直播不属于长期云端档案，在直播有效期内从详情页单独下载。仅保存在手机上的内容不会出现在后台。已删除但尚在保留期的比赛带删除标记；已清理正文的比赛不会被恢复。全部云端 ZIP 包含已解散但仍保留的球队资料。

ZIP 和 JSON 用于查看与自行保存，不是 App 的 `.bmbackup` 或球队档案导入文件。下载不包含登录密码、设备登录凭证、恢复码、邀请秘密或观看授权。后台只提供查看和下载，不修改比赛、队内角色或历史网页开放方式。

## 与 App 审核的关系

本次只增加网站后台及兼容的服务端读取接口，未修改 App 源码、工程版本、构建号、签名归档或审核材料包。用户可以继续提交已有 3.0（Build 1）归档，后台无需提供给 App 审核人员。

## 登录与运行

- 密码只在登录时通过 HTTPS 提交；服务器保存加盐 scrypt 校验值，不在网页源码或仓库保存明文密码。
- 登录有效期为 1 小时；退出、到期或服务重启后重新登录。Cookie 为 `Secure`、`HttpOnly`、`SameSite=Strict`。
- 所有资料与下载接口均独立校验后台会话，不能使用 App 设备凭证代替。登录有频率限制，页面禁止缓存、搜索索引和外站嵌入。
- 原临时直播通过仅回环地址可访问的内部接口读取，公网 nginx 拒绝该接口；内部连接另有随机密钥。
- ZIP 使用独立只读 SQLite 事务，按文件输出；导出期间 App 写入仍使用现有连接。最多同时两份 ZIP，同一登录每分钟最多五次打包；超大资料提示分别下载。

服务部署、配置位置和回滚见 [后台部署记录](../../../collaboration/deploy/2026-10-13-admin.md)。
