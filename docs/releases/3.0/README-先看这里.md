# BaseballMaster 3.0 上线材料包

App 3.0（Build 1）已完成开发、验证和最终签名归档；网站与服务已上线。接下来由你上传并提交 Apple 审核。

先看三页 **BaseballMaster-3.0-更新与使用说明.pdf**。简要更新：球队共享、比赛同步与交接、历史回看权限、按年度统计、导入旧比赛，以及时间补填／背号／换投确认。第 3 页说明如何用原本机球队创建共享球队、成为管理员、保存恢复卡和导入已有比赛。球队“名单”就是球员姓名、背号等资料。

提交顺序：

1. 按 `UPLOAD-GUIDE.md` 打开最终归档，在 Xcode 验证并上传。
2. 参考 `APPSTORE-METADATA.md`，复制包内 TXT 文案；按 `APP-PRIVACY.md` 核对隐私问卷。
3. 从 `screenshots/` 选择对应栏目的一套九张 PNG，按 01–09 上传。
4. 按 `CREATIVE-ASSETS.md`，从 `creative-assets/upload/` 选择标题与搜索结果原图，在对应创意素材栏目配置并预览。
5. 选择构建，填写真实审核联系方式，提交审核。

无需注册或审核账号。审核人员可以直接创建自己的共享球队。官网当前标明准备审核，没有提前宣称 3.0 App 已上架。击球落点与快捷局面改版、iPad／Duo、Android 和小组件不属于本版。

2026-10-13 权限补充：管理员和记录员都可新增、修改球员姓名与背号；每队最多两名管理员。成员管理、角色分配、停用／恢复球员及解散仍由管理员负责，普通成员只读。材料与最终归档包含本次更新。
