# 3.0 App 隐私填写依据

2026-10-12–13。3.0 新增可选球队协作与长期历史档案，应更新 App Store Connect 的隐私信息；不能沿用“无数据收集”。本文件是填写依据，没有替用户更改或发布问卷。

| Connect 类别 | 实际上传范围 | 用途 | 关联用户 | 追踪 |
| --- | --- | --- | --- | --- |
| 联系信息 → 姓名 | 球员姓名／昵称，成员称呼 | App 功能 | 是 | 否 |
| 用户内容 → 其他用户内容 | 球队、背号、阵容、规则、完整比赛与事件、统计投影、冲突记录 | App 功能 | 是 | 否 |
| 标识符 → 用户 ID | 球员与成员标识、来源对应关系；无注册账号 | App 功能 | 是 | 否 |
| 标识符 → 设备 ID | 随机安装身份、设备名称、球队设备关联 | App 功能 | 是 | 否 |
| 使用数据 → 产品交互 | 邀请、交接、成员变更、更正、恢复等操作审计；不做营销分析 | App 功能 | 是 | 否 |

所有上述类别均不用于广告、跨 App 追踪或数据经纪。即使共享和开播可选、没有实名注册，数据仍可通过成员／设备标识关联，不能据此填“不关联”。纯本机记分不因升级自动上传；共享需主动开启。普通备份与报告不自动发到服务端。

`PrivacyInfo.xcprivacy` 已声明上述五类数据及 UserDefaults 的 CA92.1 理由，最终归档中已核对；没有额外广告／分析 SDK 或音视频采集。问卷应按整款 App 的实际行为填写，Manifest 不代替 Connect 问卷。

- 有效实时直播链接仍允许匿名观看；历史回看默认关闭网页，队内成员仍可在 App 查看。永久开放／指定人员／关闭独立控制，不删除档案。
- 指定观看会话使用必要的 Secure、HttpOnly Cookie；转发链接不会自动授权。
- 云端比赛删除／球队解散有 30 天恢复期。过期清理正文，滚动备份保留 30 天，旧副本可能合计最长约 60 天后清除。最小删除／撤销标记持续保留，防止旧设备或旧备份恢复权限。
- 腾讯云现有服务器与独立 COS 对象存储承载业务；备份加密。旧版临时直播数据库不纳入长期备份。
- 导出完整档案不携带设备秘密、恢复码或观看授权，文件本身未加密，导出界面明确提示保管；导入为独立本机只读资料。
- 使用者可退出球队、按权限删除比赛／解散球队、撤销设备或观看者，或联系支持核实处理；无需提供秘密凭证。

公开政策：[隐私](https://baseballmaster.cc/privacy.html)、[支持](https://baseballmaster.cc/support.html)。依据：[Apple App 隐私详情](https://developer.apple.com/app-store/app-privacy-details/)。支持邮件中用户主动提供的联系信息按实际支持流程处理；审核联系资料使用开发者真实资料。

2026-10-13 权限更新仅改变已共享资料的编辑者：管理员与记录员都可新增、修改球员，每队最多两名管理员；未新增数据收集类别。公开隐私说明已同步，Manifest 保持一致。
