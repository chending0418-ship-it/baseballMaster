# 3.1.0 隐私填写依据

2026-10-20。沿用已发布版本的现有数据范围：姓名、其他用户内容、用户 ID、设备 ID、产品交互，用途为 App 功能，与成员／设备关联，不用于追踪、广告或营销分析。没有新增第三方 SDK、权限提示或新的数据收集类别。

新增球型、球场落点、传球、失误责任和跑者原因属于比赛记录内容。落点是记录员在球场示意图上的点选坐标，不是手机 GPS 位置；不采集设备定位。资料先保存在本机，仅在用户主动共享或开播后上传对应内容，旧比赛不会因升级自动上传。年度统计只使用本机及有权查看的球队记录。

基础版 / Pro 版是记录方式名称，没有订阅或内购。邀请、设备授权、球队记录、直播观看及私有备份继续按原有规则保护。不要因本次没有新增类别而将整款 App 改填为“不收集数据”。本轮没有代为修改 App Store Connect 问卷。
