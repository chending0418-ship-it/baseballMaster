# 1.6 隐私资料更新

以下是待在 App Store Connect 填写的依据，本地隐私清单更新不等于线上申报已经提交。现有网站页面也需用本目录 HTML 替换后才生效。

| 数据 | 本版实际用途 | 建议申报 |
| --- | --- | --- |
| 球员姓名 | 主动开播后显示参与该场比赛的球员 | 联系信息 → 姓名；App 功能；与用户身份关联；不用于跟踪 |
| 球队名、背号、比赛过程、比分、打席和事件标识 | 文字直播展示、修正与同步 | 用户内容 → 其他用户内容；App 功能；与身份关联；不用于跟踪 |
| IP 地址 | 传输及内存中的限流计数，最多一小时；应用不落日志 | 按实际部署核对。若另行留存 IP／访问日志或接入监控，需重新评估相应申报，不能直接沿用本实现描述 |

不上传其他比赛、完整数据库、备份、相册、音视频、定位、通讯录；没有广告、跨 App 跟踪或行为分析 SDK。可选的直播功能仍需按实际收集申报，不能保持旧版“完全不收集数据”。球队／球员标识用于关联用户提供的比赛内容，不充当 App 登录账号或设备广告 ID。

网站更新步骤：

1. 在宝塔找到 App Store Connect 当前填写的 Privacy Policy URL 和 Support URL 所对应的站点文件，备份旧网页，再分别替换为本目录 `baseballmaster-privacy.html`、`baseballmaster-support.html`。无需改变原 URL；若更换路径，同时修改 App Store Connect。
2. 核对公开页面显示文字直播范围、终场一小时删除、失联一小时关闭、持链接可看和支持联系方式。上线日期不同于 2026-09-23 时更新网页日期。
3. 直播路径禁用缓存与内容日志；直播数据目录排除宝塔备份和云快照。政策页面可正常静态托管。
4. App Store Connect → App 隐私，按上表及服务器实际处理更新并发布答案；保留不跟踪。TestFlight 测试资料与正式 App Store 版本资料分别管理。

参考：[Apple App 隐私详情](https://developer.apple.com/app-store/app-privacy-details/)。
