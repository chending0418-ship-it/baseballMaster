# 手动结束比赛后无法返回首页

记录日期：2026-10-01。最新状态（2026-10-03）：已完成修复和本轮模拟器回归，见 [开发验收记录](DEVELOPMENT-VALIDATION.md)。以下保留原始复现、草稿与分阶段测试证据。用户确认 2.1 已上线，并要求该问题在 2.2 修复。开发目录为 `BaseballMaster-2.2`，分支为 `codex/dev-2.2`，工程版本为 2.2（Build 1）。

## 复现与原因

从首页新建比赛，确认先发并开始记分；点击“结束比赛”，选择“时间限制结束”，再确认保存。比赛已结束并保存，但记分页没有返回按钮，也没有底部导航，无法返回首页、球队、统计或我的页面。

原因是本队比赛与观赛的开赛入口都对 `ScorekeepingView` 设置了 `navigationBarBackButtonHidden(true)`，而记分页为了全屏显示又隐藏了 Tab Bar。结束比赛后的界面沿用上述设置，缺少退出入口。结束原因弹窗能正常关闭，继续已有比赛的返回路径也通过了基线测试；本次没有发现整个 App 线程卡死。

修复前，新增 UI 测试 `testManualEndOfNewGameCanReturnHomeAndOpenSavedResult` 到达“比赛已经结束”后，因首页入口不存在而失败。原截图和界面层级记录保存在本机 [基线结果包](../../../output/validation/2.2/manual-end-navigation/new-game-baseline.xcresult)。

完整路径回归另确认：首页“最近比赛”的 `recentGameContent` 缺少 `.contentShape(Rectangle())`，卡片中部空白处点击无响应；“正在进行”卡片已有此设置。iPhone 17 Pro 的同一路径连续两次停在点击最近比赛的步骤，iPhone 16e 上因布局位置不同通过。现已补上整块卡片的点击区域。

## 修复行为

- 本队新比赛、观赛新比赛及从赛前设置开赛的流程，在记分页左上角提供“比赛首页”入口，进行中、中断和结束后均可使用。
- 点击首页入口使用已有的 `returnToGameHome()` 重置比赛导航栈并选择比赛首页；比赛仍按原有逻辑保存，可从首页继续或查看结果。
- 按用户截图反馈，将终场卡片内的“查看结果”改为“返回首页”；与撤销、恢复使用相同的紧凑按钮样式，保持单行文字与 44pt 点击高度。比赛结果继续从右上角进入。练习模式对应显示“返回练习”，返回练习入口。
- 从已有比赛进入记分页继续保留原返回路径；练习模式继续使用其独立的返回和重置行为。
- 从结果页手动结束后可返回记分页，再返回首页；最近比赛卡片的内容和空白区域均可点击，从首页重新打开已结束比赛可查看结果或恢复为进行中。
