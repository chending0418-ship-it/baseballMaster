## 验证

新增真实 UI 用例 Ios311ParityFlowTest（含标准布局、应用内结果页）：主按钮无需滚动可见、首球确认及持久化、撤销／恢复、特殊事件上垒、修正／换人、换边确认、终场返回；慢垒／教练投手条件入口；本机删除取消及记录隔离；四个 Tab 和批量名单、规则、设置、数据、关于。最终包 API 31 标准视口 17 项设备回归全部通过，App JVM 80 项通过；不以测试源码存在代表通过。

既有完整互导、正式赛后归档上传／旧关联更新仍未完成。旧 Build 7 用户决定暂缓的跨端互导不会被本轮 UI 改造宣称为已完成；0.8.0 的完整交付边界须在最终验收时逐项列明。

## 开发补记

- 应用内比赛结果恢复独立入口，含分局比分、R/H/E、双方打击／投手／守备数据及 PDF 导出；不用导出文件才能读结果。
- 工具栏恢复直播分享、海报、历史纠错与比赛结果；Pro 补充这球直接保留原结果／跑者去向并追加观察更正。
- 确认弹窗统一暴露测试标识，使用与 iOS 相同的暖色内容底，去掉 Material 默认紫色面板。
- 新增本机删除事务回滚／版本冲突／其他比赛隔离及来源档案保护测试。完整导入档案暂拒绝单场删除，避免损坏其整份备份与来源映射。
- 验证日志按轮保留。此前两轮在构建切换和系统 ANR 后中断；未记作通过。`parity-api37-frozen.log` 的两个确认标识定位失败已修正；`parity-api31-confirmations.log` 的取消后点击时序、`parity-api37-confirmations.log` 的长列表定位失败需由最终冻结包重跑替代，原始失败不删除。
- `verified-candidate-build.log` 的核心逻辑报告为 180 项（未改变的核心任务复用），App JVM 77 项，0 失败／错误／跳过；lint 与 Debug／Release 构建通过。后续工具栏文本及测试等待改动以 `release-build.log` 与最终设备回执为准。

- 比赛结果页按 iOS 增加“记录”分类，按打席聚合中文实况、待确认补录、单打席导出，接回修改时间、结束保存和恢复比赛。
- 历史数据加载移到 Default 调度器，按完整 GameEntity 复用已验证的未变快照，避免每次刷新在界面线程解码整库。新增 GameSnapshotDecoderTest 验证改写相同 revision 的 payload 仍重新解码，以及记录删除后的缓存淘汰；App JVM 增至 78 项，无失败。
- API37 最终六项轮次在设备连接消失后中断，不计整组通过；另启无窗口模拟器作最终核对，不覆盖已保存的中断证据。

- 第一轮扩展 Release 回归中 Pro 分段选项的选中状态断言失败；原控件点击能改变选择，但缺少 RadioButton 的 checked 状态。已改用 toggleable 语义，保留不能取消当前单选项的行为，最终 Pro 回归须重跑。

## 建赛对照补齐

逐项核对 NewGameSetupView 后确认旧 Android 缺少观赛和赛前补录。0.8.0 新增本队／观赛记录类型、两支对手的独立选择、相同队伍阻断、对手名单管理往返保留草稿、批量创建对手、补填实际比赛日期及本地时区；基础／Pro 选择移到建赛首部，规则草稿不因切换记分方式丢失。观赛通过独立原子存储入口保存，禁止绑定本队／共享上传目标，不计本队战绩或年度统计。补录的 playedAt 不被首球开赛覆盖，按实际年份统计。

新增 ObservationCreationTest 两项验证保存、终场、备份恢复、统计排除、错误角色拒绝和提交失败回滚；Ios311ParityFlowTest 增加观赛／名单管理／批量对手／草稿保留及补录年度两条设备流程。App JVM 合计 80 项。普通建赛、共享名单建赛、三模式与旧数据升级继续回归。

本轮还精简备份与只读档案页面的技术说明，保留可查看／可编辑、是否恢复球队权限、是否改动原资料等实际使用边界。
