开发分支 `codex/android-0.8.0`；Android 工作区为 `/Users/JasonChan/.codex/worktrees/android-remaining/baseball-scorekeeper`。本轮本地交付，不更新官网下载、不合并 main、不部署业务后端。

## 页面与流程

| 页面 | 本轮改动 |
| --- | --- |
| 比赛首页 | 预告／进行中／最近比赛的顺序、战绩、规则入口、开始／再开始按钮；独立删除菜单和二次确认 |
| 新建比赛 | 基础／Pro、三模式、本队／观赛、主客与阵容；独立对手选择、管理名单往返保留草稿、批量创建对手、补填过去日期及本地时区 |
| 比赛预告 | 默认只填双方队伍和时间保存，不生成占位球员；也可现在配置。安排页可改时间、管理名单；开赛前读取实际名单、设置规则并确认阵容，同一场次开始记分。恢复页面保留未保存输入，名单冲突／旧修订／写入失败保留原安排 |
| 记分 | 四种投球、击球进入场内、跑者／出局、特殊／判罚、撤销／恢复、修正、阵容、结束半局／比赛直接可达；首球及首次击球确认阵容、首球前互换、计时暂停／继续。统一保留球场，练习与附加操作允许滚动 |
| 比赛结果 | 应用内分局 R/H/E、打击／投手／守备、按打席中文记录、待确认复核、单打席及整场 PDF、修改日期、结束保存及恢复；从子页面返回结果页 |
| 球队名单 | 队徽、球队名称、当前球队、人数和整行名单入口；保留一次性批量填写全部名单；对手管理隐藏无关共享卡 |
| 统计 | 球队／年度分组、比赛模式与场次筛选、投打守指标及个人表现；观赛不混入本队战绩，补录按实际年份统计，预告按首球的实际开始时间归入比赛日期 |
| 我的 | 身份卡、学习帮助、本机数据、设置和关于；整行导航与偏好持久化 |
| 全局 | 暖白背景、藏青文字、深绿操作、卡片边框、按钮圆角及分段选择；移除默认紫色弹窗底色，同步系统栏明暗 |

历史身份和备份保留。删除本机比赛使用事务与 revision 检查；完整 iOS 来源档案暂不允许单场删除，避免破坏原档案与来源映射。未配置预告使用独立 payloadVersion 5，不能投球或计时；配置完成后使用普通比赛格式 4。旧数据及 Room 表结构不变，已保存比赛不共享可编辑草稿的球员对象。
