# Android 0.8.0（Build 8）本地验收交接

本轮按 iOS 3.1.1 已提交基线 `315580d` 核对 Android；不使用主工作区尚未提交的 iOS 3.1.2 草稿。开发分支 `codex/android-0.8.0`，iOS 源码未修改。此为本地测试交付，未更新官网下载、未合并 main、未部署业务后端。

## 页面与流程

| 页面 | 本轮实际改动 |
| --- | --- |
| 比赛首页 | 恢复预告／进行中／最近比赛的顺序和战绩文案、规则入口、开始／再开始按钮；增加独立删除菜单和二次确认 |
| 新建比赛 | 基础／Pro、三种比赛模式、本队／观赛、主客与阵容；新增观赛双方对手选择、对手管理往返保留草稿、批量创建对手、过去日期补录、本地时区 |
| 记分 | 四种投球、击球进入场内、跑者／出局、特殊／判罚、撤销／恢复、修正、阵容、结束半局／比赛直接可达；首球及首次击球确认阵容、首球前互换、计时暂停／继续；统一保留球场，练习／附加流程允许滚动 |
| 比赛结果 | 新增应用内比分及分局 R/H/E、打击／投手／守备、按打席中文记录、待确认复核、单打席及整场 PDF、修改日期、结束保存及恢复；从子页面返回结果页 |
| 球队名单 | 恢复队徽、球队名称、当前球队、人数和整行名单入口；保留用户确认的单对话框批量填写全部名单；对手管理不再显示无关的球队共享卡 |
| 统计 | 恢复球队／年度的分组布局；沿用比赛模式、场次筛选、投打守指标与个人表现；观赛不混入本队战绩，补录按实际年份统计 |
| 我的 | 身份卡、学习帮助、本机数据、设置与关于分组；整行导航；保留外观、帮助偏好和本机数据恢复能力 |
| 全局 | 对齐暖白背景、藏青文字、深绿主操作、卡片边框、按钮圆角与分段选择；移除默认紫色弹窗底色；同步系统栏明暗 |

名单、记录、历史身份和备份继续保留。删除本机比赛使用事务与 revision 检查；完整 iOS 来源档案暂不允许单场删除，避免破坏原始档案及来源映射。

## 交付边界

- 完整 iOS／Android 双向互导延续用户此前暂缓的决定；正式赛后球队归档上传和旧云端关联更新仍未交付。
- 预告比赛目前按完整阵容确认后保存，尚未实现 iOS 的“只填基本信息，开赛前再补名单”路径。这是已核对出的流程差异，不能宣称已经 100% 复刻。
- 原生系统分享、文件选择和系统权限面板保持 Android 行为；本轮没有更改 iOS，也没有把 Android 批量名单移植到 iOS。
- 覆盖模拟器测试，不把它写成实体手机或所有厂商机型验收。模拟器内保留合成回归球队和比赛；交付 APK 不预装这些测试资料。

源码已本地提交在 `codex/android-0.8.0`；构建源码 `e88575e`。无 main 写入或远端部署。
