## AN01 范围冻结

- F01–F14 全部纳入首版，已细化为 [48 条用例](../../../test-fixtures/android-parity/scope.json)，列明页面、触发动作、预期和阶段。完整迁移用例仍为 planned，不把盘点完成算成功能验收完成。
- 三个 [iOS 参考样本](../../../test-fixtures/android-parity/README.md) 经专用 iPhone 16 模拟器实际运行 XCTest 导出，共 24 次投球、3 个初始状态；Kotlin 逐步比较 27 个状态子集。保留实际 iOS 初始 payload 和 manifest SHA-256，用于后续格式适配。
- 固定 Kotlin／Compose／Room；最低 API 31、编译及目标 API 37；主尺寸 360／393／412／432 dp；本轮采样 360、约 412 dp。正式标识 `cc.baseballmaster.scorekeeper`，首版 1.0.0；开发预览使用独立包名与版本，不改变 iOS 标识／版本。
- 协议保持 1，新共享比赛格式 2，Swift payload 的 2001 年秒数与 API Unix 毫秒显式区分；稳定 UUID、00 背号、幂等／修订／记分代次和权限按现行服务保留。
- 用户再次确认：不同用户通过 iOS 或 Android 加入同一共享球队，按管理员／记录员／成员角色查看、记录和交接，不建立平台专属数据空间。真实跨平台联调为 AN05 必须通过项，本 APK 尚未接入共享服务。
- 视觉以当前 iOS 源码和原生截图为依据。首页、卡片、比分／B-S-O、球场几何、姓名背号和投球按钮按其调整，Android 系统字体、状态栏、键盘及返回手势按平台处理。
- 官网下载沿用 `https://baseballmaster.cc/scorekeeper.html#download`，扩充现有下载区；不新增 `/android/` 产品页，本轮未改官网或部署。

## AN02 实现

- 已安装并校验官方 Android Studio、SDK、JDK 和 Gradle，已验证 Apple Silicon Hypervisor.Framework 加速；工具及构建方法见 [Android README](../../../android/README.md)。
- 原生建队／名单录入、新建比赛及三模式初始设置、四种投球计数、本机比赛列表与继续记录。名单支持 00；开赛要求双方普通／教练至少 9 人、慢垒至少 10 人。完整阵容与所有规则仍由 AN03 接续。
- 纯 Kotlin 核心、ViewModel 和 Room 分层；设备秘密由 Keystore AES-GCM 加密，排除系统备份。当前不注册服务器设备，也不从普通备份复制身份。
- 比赛 JSON、操作 ID、baseRevision 原子提交；重复请求不重复记球，冲突拒绝，注入提交失败完整回滚。未来库／payload 格式保留原件并拒绝不兼容访问，无破坏性重建。
- 两代同签名预览 APK 覆盖安装；Room 1→2 增加 payloadVersion，比赛 ID、修订与完整 payload SHA-256 一致，设备秘密指纹一致。
