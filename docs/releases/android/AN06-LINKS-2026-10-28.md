# AN06 邀请／配对系统链接（2026-10-28，第一组）

基线 `22576da`，按现行 iOS 的 `/join#secret`、`/pair#secret` 和 `baseballmaster://join#secret`／`baseballmaster://pair#secret` 迁移，复用同一服务。没有自动加入、自动配对授权或自动转移记分权。

## 应用接入

Manifest 声明固定 HTTPS 两条路径及其尾斜杠、现行自定义 scheme。MainActivity 处理首次启动和 singleTop 的 onNewIntent；在内存中提取链接后清掉 Activity intent.data，不把原秘密写进 SavedState、日志或业务导出。

完整链接再经过严格解析：固定域名／scheme／路径、无 query、无 userinfo／显式端口，秘密为规范 32 字节 Base64URL。配对与邀请分别路由到正确的核对页，不能互用。非法链接只显示固定错误文案，不回显原输入。

用户打开的有效链接写入独立加密目录，最多保留八份，同一类型／秘密去重；保存失败不丢掉旧待办。普通启动发现待办时先提示“继续核对／关闭此链接”，未确认不联网。明确打开的新链接可以直接进入相应核对页；入队本身不会注册设备或授予权限。完成加入或明确关闭后仅移除相应链接，不清掉结果未明的持久请求。多份链接按顺序处理，不覆盖当前输入。

邀请页仍先预览球队／角色，再输入称呼确认加入；配对页仍须选择球队、查看身份和四词短语、明确勾选一致才授权。任何网络结果不明均保留原 operationID／正文续取。
