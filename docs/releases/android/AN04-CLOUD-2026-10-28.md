### F09 安全读取与只读球队档案

- `.bmbackup` 校验扩展至比赛结构、规则、日期／时区、统计值、名单／打序、事件／打席身份及非递归历史检查点；保持旧版本可选字段语义。
- 外部 JSON 在解析前拒绝损坏 UTF-8、重复字段（含转义后的同名字段）、控制字符、无效数字／字面量、残缺 Unicode 代理对和过深嵌套。
- `.bmteam` 校验每行原始 payload 的哈希及完整原文封印，保留不同的本机／共享比赛身份，不错误要求两种 ID 相同；拒绝“已清除但未删除”的矛盾标记，限制单行及总量。
- 新增本机只读档案库：先暂存并校验，再明确确认；按原始字节保存和导出，不重新序列化；以内容哈希去重，原子且不覆盖已有文件。失败、取消、过大文件、暂存变化及竞争目标均保护已有文件。
- 可以离线查看名单、停用球员、比分、回收站及清除标记；不写入当前球队／比赛库，不恢复共享授权。

**边界：**结构检查不等于每个历史命令关联内容都能完整重放；只读档案不是可编辑比赛互导。当前档案页只显示名单和比分，完整历史仍原样保存在文件中；详细报告阅读及编辑转换尚未接入。`.bmteam` 本机文件暂不包含在 `.bmandroid` 中，界面明确提示另行导出保管。
