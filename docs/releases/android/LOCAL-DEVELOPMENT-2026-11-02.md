## 环境与执行方式

Android Studio、JBR 25.0.3、SDK／Build Tools 37、Gradle wrapper 和模拟器可用。启动本机 `bm-api31-360` 与 `bm-api37-412`，分别为 `emulator-5556` 与 `emulator-5554`；系统及实际窗口以各轮 `device.json` 为准。两套模拟器原有预览版本号为 6，本轮以 `-PpreviewVersionCode=6` 构建覆盖，未卸载或清数据，不递增 iOS 版本。

本机终端未继承系统 HTTP 代理，官方 Maven 下载直连超时；Java 还缺少本机系统信任的代理 CA。本轮仅在忽略的 `output/cache/android/tooling/` 建本地构建信任库，沿用系统已信任公钥，保持 TLS 校验，并按官方 SHA-1 校验补充下载依赖；没有关闭证书校验或改系统信任。凭证、私钥和用户数据均不进入代码。代理与信任库为本机设置，不应复制到其他主机。

开发初期并行构建曾争用 Kotlin 增量缓存；已停止并行 Gradle、移除受影响生成缓存并按串行方式重建。失败日志保留。后续 Gradle 应串行执行；不同模拟器的独立界面回归可并行。

设备端关闭 Wi-Fi 与移动数据，测试使用合成资料；共享名单界面注入 fake transport。协作／直播协议回归仅在回环地址及内存 SQLite 运行。没有用默认生产共享入口做测试，没有部署、公开下载或正式签名。

证据根目录：`output/validation/android/2026-11-02-local/`。构建日志在 `build/`；每轮目录保存原始仪器输出、结果、设备信息、截图和层级。失败轮保留，修复后的结果另开新目录，不覆盖为成功。
