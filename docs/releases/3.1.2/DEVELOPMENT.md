## Duo 手动下载环境

- [Apple 下载页：Simulator Runtime](https://developer.apple.com/download/all/?q=Simulator%20Runtime)：需要登录；查找 iOS 27.1 Simulator Runtime 或与已安装 Xcode 相容的新版本。

## 批量队员名单（本轮新增）

用户确认本机球队、对手及共享球队均支持，默认仍使用原有单人编辑表单，在名单页与新增队员页提供“批量输入”入口。

格式为每行 `姓名,英文名,背号`，可含同样的表头；支持中文／英文逗号、空行、CRLF 和 BOM。姓名与英文名至少一项非空，英文名和背号可留空；背号沿用 0–99／00，保留 00 与 0 的区别，每批最多 200 人。严格三列，错误显示原行号；重复整行会阻断整批，已有同名／同背号仅警告，不自动合并身份。

先预览，再确认整批新增。预览与取消不写名单；本机／对手使用一次事务，保存失败不改内存或持久快照，输入保留。共享使用 roster 的 `kind:players` 单请求与数据库事务，不逐人联网；固定请求及球员身份，支持权限／容量／revision 校验、幂等重试和持久化整批草稿。冲突后需明确刷新并重新预览确认；旧服务缺少 `bulkRosterImport` 能力时明确保留输入，不降级为逐人写入。共享后端改动尚未部署到生产。

新工具链已可用：Xcode 27.2（27B52），无需继续等待许可。本轮会用隔离的 27.2 构建缓存重新验证 iPhone／iPad；Duo 虽检测到对应运行时，依用户最新指令不操作。
