# iOS 3.1.2 App 隐私申报依据

核对日期：2026-11-04。此文是 App Store Connect 填写依据；没有发布隐私政策、修改后台问卷或完成上海迁移。正式对外正文及环境字段由本版隐私／支持页面稿维护。

## 当前清单与建议回答

`BaseballMaster/PrivacyInfo.xcprivacy` 明确声明以下五项，均为 **App 功能、与用户身份关联、不用于追踪**。沿用该范围核对后台，不能因不注册或共享可选而改填“不收集数据”。

| 数据类别 | 实际内容与用途 | 用途 | 身份关联 | 追踪 |
| --- | --- | --- | --- | --- |
| 姓名 | 用户输入的球员中英文名、成员称呼等；名单、比赛展示和授权访问 | App 功能 | 是 | 否 |
| 其他用户内容 | 球队资料、名单与背号、比赛正文、球型／落点／守备路线、统计与共享／直播展示内容 | App 功能 | 是 | 否 |
| 用户 ID | 球队成员等服务内标识，维护成员关系与访问权限 | App 功能 | 是 | 否 |
| 设备 ID | 自有服务的设备授权标识，用于配对、权限及记分交接；不是广告 ID | App 功能 | 是 | 否 |
| 产品交互 | 共享、修订、交接、授权、恢复及必要操作记录，用于功能执行、安全与纠错 | App 功能 | 是 | 否 |

现有清单无追踪域名，UserDefaults 必要原因代码为 `CA92.1`。本版未发现新增广告、第三方统计 SDK 或相机／麦克风／定位权限请求。比赛球场坐标为记分员在示意图上的点选，不是设备 GPS；背号、击球统计与比赛记录不自动等同健康资料。

## 本版处理变化

- iPad／Duo 重新布局和草稿保护不新增数据类别；保留尚未确认的本机记录草稿。
- 批量输入多位队员，内容仍为姓名、英文名、背号。先预览再确认；本机名单保存在本机，共享名单确认后发送到自有球队服务。生产服务尚未更新批量能力，客户端会说明并保留输入。
- 球员详情落点图只使用当前已记录且有权查看的比赛，继承既有击球内容，不补造缺失坐标。年度、球队、模式和比赛筛选在本机计算。
- 本机比赛完整原件、独立赛后确认上传、原本机文字直播沿用 3.1.1；升级不自动上传旧比赛。共享与本机资料分别管理，不把一方删除解释成所有副本立即清除。
- 可配置开屏会在启动时向自有服务请求公开配置，必要时下载同域图片；不发送球队／比赛正文或设备授权，不使用 Cookie，阻止跨域跳转。不能把整款 App 写成“只有主动共享／开播才会联网”。服务及代理仍会处理必要请求网络信息。

## 服务、可见范围与删除

共享球队成员按角色访问；临时直播有效链接持有人可以看公开投影。直播入口关闭成功、终场一小时或连续一小时未同步后失效，与球队长期档案、另行授权的历史网页分别管理。不要承诺“所有比赛云端资料一小时后删除”。

App 支持退出球队、管理员解散球队、关闭直播／历史网页、导出档案等操作。解散后 30 天恢复窗口、到期正文清理及必要最小审计依据见 `collaboration/PROTOCOL.md` 和 `BaseballMaster/TeamSecurityViews.swift`；备份副本按实际保留策略到期，不能写成同步即时抹除。身份和资料权利请求通过正式支持渠道核对处理，不收集设备秘密、恢复卡、授权链接等敏感凭证作为公开反馈。

## 正式发布前的环境核对

当前生产仍为既有香港环境。上海隔离测试、候选配置和 COS 恢复演练不代表真实资料已迁移。正式发布须依据实际启用环境核对：运营主体、云服务提供方、主存储／备份地域、备份及安全日志期限、迁移过渡副本和删除安排。上海启用后才切换对应地域表述，不提前声称“仅存境内”。

需把公网代理访问日志、IP／请求信息、故障日志与支持邮件的最终处理范围纳入问卷核对；IP 是否留存／用于粗略位置、请求日志保存期限、主动客服邮件是否满足可选披露条件，都不能仅凭 App 隐私清单判断。本轮未访问生产私有日志，不根据源码猜测最终保留期限。若最终发现清单外的需披露内容，应同步隐私正文、问卷与适用的隐私清单，而非照抄旧问卷。

审核邮箱仅为联系渠道；不因无需邮箱注册就宣称开发者永远无法收到邮箱信息。App 内核心使用不采集邮箱／手机号；用户主动发邮件另按实际客服处理范围说明。
