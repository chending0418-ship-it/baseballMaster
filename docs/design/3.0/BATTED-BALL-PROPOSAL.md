## 用户要求与已确认文字

每一个打席可查看当前打者的本场或年度打击表现，包括本队及对方打者。年度范围只包含我们实际记录到并有权查看的比赛；不是该球员完整生涯。记录击球时补充球型和大致去向，以生成击球分布图。

球型依用户指定顺序使用 **地滚、强力地滚、平飞、高飞、内野小飞、触击、没有看清**。同组单选，去掉原提案的独立「短打」开关。强力地滚是记录员的现场观察，不换算为击球速度；「触击」先作为一个主类别，不再强迫同时选择其他类别。

快捷入口：一垒安打、接杀、滚地出局、双杀。投球按钮继续使用已确认的「坏球｜好球 - 看｜好球 - 挥空｜界外」。

## 推荐流程

1. 现场记分的打者栏只保留棒次、背号和姓名，不添加「查看表现」等说明或本场成绩小结；点击当前打者直接打开「打击表现」，不改变打席或球数。切换「本场／2026 年」查看汇总和击球图；关闭后回到同一个局面。
2. 点「击球进入场内」，或从常用局面选相应结果。快捷项只预填结果，没有确认之前不改比分、统计或出局数。
3. 新增观察页只选择上述七个球型之一及球场的大致落点。也可按区域选择、标记没有看清位置，或先记结果，稍后补资料。
4. 完成观察后接回原来的局面记录流程；已有快捷结果沿用并从尚未完成的步骤继续，没有选结果时回到原有结果选择。原来的守备、跑者、第三出局与得分判定、提交及撤销流程继续使用，不另外增加一套结果选择或确认流程。球型和落点先保存在本球草稿中，在原流程提交时一并保存；取消本球草稿不留下单独的观察记录。

2026-10-12 用户进一步确认：选完球型和落点后即可回到原来的流程。新增内容是一个可衔接的观察步骤，不重新设计完整局面记录。此前演示中的结果／跑者／确认页面用于说明后续衔接，不作为替换原流程的实现要求。

### 两种快捷入口位置

- **展开快捷菜单（备选）**：保留现有球场，把「击球进入场内」做成主入口和右侧「常用」展开入口。展开后横排显示四个常用结果，菜单覆盖操作区，关闭后恢复。
- **击球面板第一屏快捷项（建议）**：记分页保持单个击球按钮，在弹出的「记录击球」页面顶部横排显示四个常用结果，下面保留按打者终点进入完整流程的入口。

2026-10-12 阅读「V2 局面记录优化」后，建议以 V2 的面板内「常用击球／全部击球」为基线：点击球后直接展示常用结果，不藏进面板内的第二层菜单。外部折叠菜单和内部第一屏都需两次点击才能选到局面，外部菜单不减少点击；常驻外部一行则占用主页面空间。当前演示仍保留两种入口作比较，完整六项常用／全部目录及同屏展开应在下一轮合并提案中呈现；尚未据此开发。

### 预填边界

- 一垒安打：只带入结果，不能推出球型或去向。
- 接杀：继续选择平飞、高飞、内野小飞等实际观察，不自动标成高飞；仍需核对参与守备者。
- 滚地出局：可预选地滚，用户可改为强力地滚、触击或没有看清；守备传递仍按原流程核对。
- 双杀：只带入双杀结果，不预设为地滚球或固定 6–4–3；必须核对两个实际出局者和必要的得分时序。
- 跑者终点只给建议，必须允许按真实局面更改。不能因选了安打就忽略跑者被触杀或额外推进。

## 去向如何记录

使用「击球去向」作为总称。腾空球记录落地／接杀的位置；地滚球记录野手处理或球停下的大致区域。图中的线只是从本垒连接去向，不表示实际飞行轨迹、弹跳路线、速度或米数。

触击同样允许记录去向；没有看清球型但看到了区域，或看清球型但没看清位置，可分别保存。正式实现应区分点选位置与仅选择区域的精度，不能把区域中心当作精确实测落点。

普通界外球继续使用原快捷按钮，不要求每一球打开新流程；界外接杀在正式设计中应允许记录界外区域。本垒打需区分大致方向与实际出墙结果，不凭场地图坐标自动判断。观赛、教练投球与慢垒沿用各自规则，禁止的触击等选项按规则限制，不能因为新的球型分类绕过原规则。

## 查看页与年度数据

- 显示打席、安打／打数及打击率，同时展示击球去向；这些汇总与击球图覆盖数量分别标注。
- 图上不标左外野、中外野、右外野、三垒侧、一垒侧等位置名称，只保留场地轮廓、方向线和落点。颜色区分安打、出局和失误／其他结果，球型在标记中用「地、强、平、高、小、触」等文字说明。点标记显示比赛日期、局次、完整球型及本球结果。
- 没有位置的击球计入适用统计，但不伪造图上位置；保送、三振等没有击球去向的打席不画线。例如示例年度为 8 打席、7 打数、3 安打，6 次击球有位置、1 次击球缺位置、另 1 打席为保送。
- 本场当前尚未结束的打席不提前计入已完成汇总。
- 年度按保存的比赛时间及既有年度规则归类。三种比赛模式分别筛选或明确标识，避免把不同规则的数字混为同一成绩。
- 本队和对方都按稳定球员身份汇总。不同球队或来源中同名／同背号不自动合并；临时、未知人员继续标记待关联。对方年度数据只代表我们记录到的比赛，不能冒充对方全部正式成绩。
- 共享副本只采用最新正式修订，不能重复汇总本机原场次和导入副本。历史更正、撤销／重做后，图和统计一起更新；只读成员查看入口不授予修改权限。
- 老比赛没有球型和位置的部分保持未知；不根据安打结果、传球顺序或文字猜出精确去向。需要时通过现有更正流程人工补充。

## 开发影响

正式实现需要为击球／打席增加观察字段，绑定球员身份、打席及比赛修订；接入本机保存、撤销／更正、备份／恢复、完整比赛同步，以及双方打者的本场／年度查询。现有安打、出局、牺牲等计分逻辑继续根据结果及守备／跑者裁定；「强力地滚」本身不直接改变统计。仅凭当前的结果枚举无法可靠生成击球图。

网页和报告若展示新图，仍须遵守既有直播／历史观看权限，不能借打者年度入口泄漏别的私有比赛。功能已确认纳入 3.1；尚未开发，具体布局及网页／报告展示范围在 BB01 中细化。
