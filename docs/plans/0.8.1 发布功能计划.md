## 本版增量功能

本版以 iOS 3.1.0／3.1.2 的实际模拟器 App 和源码流程为参考，继承 0.8.0 已有记分、统计、导出、共享及直播能力；Android 系统文件选择、分享和权限面板保留原生行为。

| 功能 | 最终范围 |
| --- | --- |
| 四个 Tab 与信息层级 | 紧凑比赛行和战绩，胶囊导航、球队／个人图标；“我的”展示本机记录员、当前球队和保存身份，版本移到关于页 |
| 新比赛与预告 | 按记录方式、球队、主客、时间、规则和赛后共享分组；保留观赛、补录、队伍搜索与共享来源，往返阵容确认保留完整规则草稿及无效输入 |
| 赛前阵容 | 双方逐人编辑，候补替换、守位交换、上场复用、箭头／长按排序；固定确认按钮和二次确认 |
| 赛中阵容与换人 | 阵容编辑与换投／代打／代跑分开，标示当前／下一打者与跑者；未保存退出可继续、放弃或保存；保留球员身份、DH 只换投手及慢垒额外打者守备关系 |
| 基础／Pro 记分 | 基础版结果卡和按需核对，简单球一次提交；Pro 初始直接显示球场，球型、落点、传球与失误责任共用一份草稿，逐人核对跑者原因 |
| 纠错、终场与结果 | 数值步进、球员菜单、结束原因和二次确认；结果页分局 R/H/E、投打守表及中文打席记录，保留纠错和导出 |
| 个人统计与筛选 | 紧凑横排身份、年度／场次筛选、顶部 PDF 导出、单返回；首屏 AVG／OBP／SLG／OPS，保留完整计数、近 3／10 场与逐场选择；筛选草稿取消不应用，旋转保留 |
| 个人击球落点 | 按真实已结束比赛、球员身份和已应用记录投影，跟随筛选；未知不绘点，区域不伪造精确点，可点选查看日期、比分、局次和原文 |
| 折叠展开工作台 | 同屏比分、分局、球场、投打、阵容和实况；Pro 页内编辑时锁定其他现场操作；固定队名及 R/H/E、局数独立滚动、球型两排、完整 260dp 球场、宽结果表 |
| 状态与提示 | 旋转、展开／收起保留同一草稿；深浅色完整；规则提示仅在实际触发时出现；返回一次退一级、取消不提交、终场未完成打席明确说明 |
| 数据保护修复 | 赛前设置历史清理后再开赛，避免首球误报过程不完整；资料更正、名单与比赛同事务，失败或修订冲突不部分落盘；长比赛不塞入 Activity Bundle |
