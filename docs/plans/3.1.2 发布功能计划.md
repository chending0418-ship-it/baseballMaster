## 本版功能

| 功能 | 最终实现与边界 |
| --- | --- |
| 原生 iPad 适配（I312-01–05） | 设备族 1／2，iPad 四方向与可缩放单场景；首页限宽，现场使用双列工作台，常驻分局比分、球场、投打／待打、阵容、实况和最近打席；窄窗重排 |
| 页内 Pro 记录 | 宽屏直接在右侧录入，完整球场与确认区自然展开，由整页统一滚动；不再使用截断球场的固定高度／内部竖向小窗口。普通 sheet 保持自身滚动及底栏 |
| 草稿与记球保护（I312-04） | 旋转、窗口变化和 Duo 折叠保留球型、落点及守备草稿；编辑时锁定会改变比赛上下文的操作。取消不记球，确认仅一次，撤销／恢复可用 |
| iPhone Duo（I312-07） | 适配真实内外屏、半折叠、系统竖排工具栏、开屏安全区域及分享返回；沿用同一草稿视图身份。证据为专属模拟器，不宣称真机或任意尺寸已穷举 |
| 紧凑顶部与分局表 | 宽屏将比分与 75 点默认紧凑分局表并排；白色主题卡片、限宽局数列、当前局局部高亮、R／H／E 对齐，宽屏练习提示单行。Duo 默认展开首屏完整显示球场、投打条及主要操作，大字允许滚动 |
| 批量队员名单（I312-15） | 本机球队、对手与共享球队均可批量输入；默认单人表单保留。每行“姓名,英文名,背号”，先校验／预览再整批确认，预览和取消不写入；共享采用事务及幂等请求，未知结果、权限或修订冲突保留草稿，不降级为逐人写入 |
| 统计页球员落点（I312-16） | 球员详情打击分类复用统一球场，跟随年度、球队、模式和比赛筛选；区分精确点／区域／缺失，标记及逐球列表可查看详情，空筛选不回退全量，历史坐标不改写 |
| 球员对应后更正上传（I312-08，原 I311-10） | 修复纯球员对应变更导致合法更正无法上传的 P2；保留真实正文并发、权限、交接及过期审阅保护 |
| 投手额度换局计入（I312-17） | 自动换局沿用 A 不预占新局，A 实际投球后才计入；确认 B 登板仍计一局。两局限制、A 首局投完后在二局换 B：A／B 各用一局、各剩一局。保留同局去重、撤销恢复和独立统计 IP；旧记录不明时提示核对 |
| 继承 3.1.1 | 本机完整原件、原本机直播、独立赛后确认上传、完整 Pro 结果、完赛返回、统一球场及可配置开屏全部保留；旧记录和发布遗留不被自动勾选 |
