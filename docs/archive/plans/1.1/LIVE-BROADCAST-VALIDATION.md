# BaseballMaster V1.1 直播实现与验证

日期：2026-09-23。分支：`BM_1.1_dev`。已完成 App、网页和服务器本地实现，未部署到 jingsen.cc、未归档送审。

## 采用的最新范围

- `https://jingsen.cc/baseballmaster/live/<串码>`，24 位随机场次串码。
- App 分享链接／二维码，观看者无需口令或账号；网页前台每十秒刷新。
- 当前比分、局面、普通投手累计球数／教练本打席球数和按半局组织的打席过程。
- 终场一小时后删除直播记录和访问地址，不保留回放。连续一小时未同步也关闭；手机比赛和备份保留。
- 已确认用户使用宝塔。交付 Node 24 服务、Nginx 路径配置、部署包和操作说明，不替用户远程部署。

## 实现位置

- `BaseballMaster/LiveBroadcast.swift`：公开投影、稳定打席／事件关联、Keychain 绑定、发布／补传、冲突和删除竞态处理。
- `BaseballMaster/LiveBroadcastViews.swift`：开启、二维码、系统分享、同步与关闭。
- `GameStore` 在本地保存成功后触发发布，App 前台每十秒心跳；新增字段不替换旧本地资料库，不要求用户联网迁移。
- `live/server.mjs`：HTTP + SQLite、字段校验、发布鉴权、修订控制、到期清理；`live/public/` 为无框架观赛页。
- 协议：[PROTOCOL.md](../../../../live/PROTOCOL.md)；部署：[README.md](../../../../live/README.md)；隐私交接：[PRIVACY-RELEASE.md](../../../../live/PRIVACY-RELEASE.md)。

## 留给部署后的检查

- 宝塔上实际 Node 24、端口、HTTPS、原网站路径无回归、进程开机启动和域名缓存。
- 按部署文档排除直播数据库的备份／磁盘快照，关闭该路径内容日志及 CDN 缓存；代码备份可保留。
- 真机 Safari、微信内置浏览器、公网网络与终场一小时的实际等待检查；iOS 后台不承诺持续上传，终场需等“已同步”。
- 旧版 App 真机覆盖升级依然是版本发布阻断条件。本轮模拟器回归不替代该检查。
- 已更新 App 内隐私说明和清单，另有新版隐私页面草案；生产隐私页面与 App Store Connect 答案尚未发布／修改。
