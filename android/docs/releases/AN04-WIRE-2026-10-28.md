# AN04 Swift 数据模型互读检查（2026-10-28）

基线：`df142ec`，分支 `codex/android-migration`。**AN04 进行中，完整互导尚未验收；AN05–AN07 未完成。** 用户已要求自行统一做界面测试，本轮不启动模拟器、不运行 UI 自动化、不制作截图或交付中间 APK。

## 本轮代码

- Android 原生比赛的研究编码器补入当前打席投球数；初始检查点具有确定的打席身份，每条操作记录后续打席编号，避免后续重放自行生成身份。
- 原生纠错与撤回的研究编码包含每份更正前 journal、原操作 ID、appliedOperationIDs、原因、摘要和审计日期；保留 edited／inserted／acceptsNewContext、附加失误及统计裁定。事件携带已有 reviewNote／reviewedAt，保留 needsReview 和比赛 statisticsIncomplete。Android 没有记录的逐事件复核日期不捏造。
- 研究编码／重放补充换投、代打、代跑、守备换人及换守位。当前守位从正式守备映射生成，不把球员默认守位冒充当时守位；保送／三振责任字段随状态输出。代打时打席保留前后打者 ID 链，事件仍指向当时打者。新回归核对代跑后的原投手责任、已退场球员、打序／守位及观察路线姓名快照。
- 编码返回前再通过完整 envelope／StoredGame 结构检查。已有真实 iOS 与历史原型样本保持原字节、来源和哈希；旧原型输出的回归改为逐字段比较，只单独核验新增的打席计数／身份字段，未覆盖旧样本冒充新 iOS 执行证据。

## 独立 Swift 编解码检查

新增 `scripts/android/swift-wire-check.py`、`scripts/android/swift-wire/main.swift` 及显式的 `:core:swiftWireTest`。使用免费 Swift 6.2.3 Linux 工具链；没有购买服务或访问生产。工具链、编译产物和生成备份均位于 `output/`，不提交二进制。

脚本使用仓库当前真实源文件：完整 `Models.swift`，以及以唯一声明边界截取的 BattedBall、SituationRecording、HistoryCorrection 数据模型、RosterSnapshot、MatchPlayerLink。仅将未使用的 SwiftUI import 换成 Foundation、移除截取后未使用的 CryptoKit import；不改 Codable 定义、不添加替代结构或假实现。源文件及截取内容哈希、Swift 版本、编译输出随证据保存。声明边界变化会直接失败。

Swift 解码 RosterSnapshot、重新编码并用应用的 Equatable 数据模型检查往返；每份历史检查点另解码为 GameState 检查。缺少必需 teams 字段的负向输入必须以退出码 1 拒绝，不把进程崩溃当作拒绝通过。Kotlin 再读 Swift 返回的备份，核对比赛／事件／日志／打席／纠错／操作身份及操作关联，检查点原始 Data 字节，并比较 Kotlin 重放结果。缺少目录或文件、源码输入在 Swift 检查后变化、空结果均失败，不能静默跳过。

普通 `:core:test` 排除依赖外部 Swift 产物的返回检查；`swiftWireTest` 必须显式提供真实产物目录。普通核心测试另生成本轮 5 份合成备份：原生纠错、原生撤回、当前打席、复杂换人，以及保留原始 iOS envelope 的纠错后续投球。**这些新样本的 Swift 执行平台是 Linux，不能称为真实 iOS 生成的样本。**

复现（先配置 JAVA_HOME、ANDROID_HOME 和 SWIFTC）：

```sh

scripts/android/gradle.sh :core:swiftWireTest -PswiftWireDirectory="$PWD/output/validation/android/swift-new-run"
# 不传 input 参数时，检查仓库现有的 13 份备份；输出目录必须是新的。
python3 scripts/android/swift-wire-check.py --output output/validation/android/swift-reference-run
```

## 结果与剩余边界

本轮 JVM、构建、lint 及两组 Swift 互读的最终结果在冻结记录中登记。曾保留的失败包括旧字节快照因新增字段变化、原生事件没有独立 reviewedAt 而测试作了错误假设，以及返回检查使用相对输入路径；均按实际模型和路径修复，未改写 iOS 原始样本。

以上只能证明模型能读取、原身份在模型往返中保留，以及 Kotlin 重放一致。**没有运行 iOS App、GameStore、Core Data 导入／恢复、实际纠错撤回或共享服务客户端。** Swift Codable 解码也不会证明未知字段不会被丢弃；正式导入仍须保留原始字节并拒绝不支持的编辑。

原生研究编码仍未接入正式界面。它尚未完整复现 iOS 的“一次操作可能产生多条时钟／终结投球事件”及全部复杂指令，不能把 5 份模型互读当作完整可编辑互导或记分权交接。原始 iOS envelope 的受限非终结投球续记继续使用保留原字节／事件身份的独立链路，不得用研究编码器重写它。

仍需继续：完整操作与多事件映射、复杂纠错／撤回在实际 iOS 重放中的一致性、完整比赛批量导入的事务与原库保护、旧格式和真实 v5 样本、.bmteam 完整可编辑映射。实际 iOS 数据测试受本机无 Xcode 限制；API31／37 界面按用户指示未验证。AN05 权限／同步、AN06 系统与直播、AN07 全量验收不提前勾选。没有正式签名、公开下载、main 合并或生产操作。
