## 产品流程

- 打开页面只读取设备加密状态；必须明确点“启用球队共享”才注册／刷新设备。不会启动时自动联网，也不会自动上传本机球队。未刷新目录明确标为本机缓存，操作先核对权限。
- 空白建队或明确从本机球队创建共享副本、邀请预览后加入、共享队列表、球队资料、现役／停用球员、成员角色／移除、单次邀请／撤销、退出球队。创建与加入称呼独立；同名球队／成员及球员显示编号尾部帮助区分，实际操作始终用完整 ID。
- 从本机发布只读取当前现役名单，绑定与源球队独立。名单分页显示，每次增加 50 条，避免一次渲染全部 2000 份档案；没有静默丢弃后续球员。新增输入保留 0／00，编辑不会改来源身份。
- 邀请预览与原输入绑定；用户改输入即失效，迟到的旧预览不成为新链接的确认。提交冻结用户实际输入。名单／资料编辑冻结开始时的修订，不随缓存刷新静默采用新版本。
- 请求先保存，再关闭输入表单并发送；未知结果显示续取入口，禁止另起正文／编号。明确服务拒绝可由用户确认后保留为待核对；提示原操作可能已执行，绝不自动重做。新增重试前先清除旧拒绝证明，避免丢失新响应后误用上一次错误码来清空请求。
- 管理恢复卡提醒、明确查看／复制、标记另存和明确轮换旧卡。查看前核对当前版本和权限；其他管理员不能从服务器读回旧秘密，只能明确更换。刚创建的有效单次邀请链接也只通过明确查看／复制展示，秘密在 URL fragment。

邀请输入使用掩码、secure Dialog，不进入 SavedState；秘密显示弹窗请求 SecureOn，离开前台即隐藏。复制内容标为敏感，五分钟后尽力清除且不清掉用户后来复制的其他内容。**没有验证系统实际行为；进程结束／后台剪贴板访问受限时不能保证清理时限**，因此界面仍要求及时保存并清除剪贴板，不承诺强制远程收回秘密。
