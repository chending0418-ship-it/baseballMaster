# 棒球比赛记录大师 Android 1.0.2 发布功能计划

2026-11-10。Android 1.0.2（Build 13）修复 1.0.1 的语音击球建议丢失。官网现行版本是 1.0.1（Build 12）。

- 录音后，把可核对的击球建议和确认按钮放在转写之前。打者安全上一垒、原一垒跑者明确推进、局面一致且无失误或出局线索时，可在基础记分直接确认一垒安打。
- 缺少判定时，保留能与当前局面对上的打者、跑者去向和 Pro 落点，打开现有击球编辑供补选。明确选择结果后才进入核对，最终只写一次。分析器的内部备注、球员 ID 不显示。
- API 37 手机模拟器通过 11 项语音检查。使用去标识的同类转写和模拟解析，确认基础记分一键记入一垒安打和两人去向，信息不足时补选判定后保留跑者去向。验证确认前零写入、确认后写入一次。实况麦克风与生产解析另验。
- API 31 模拟器从 1.0.1 Build 12 覆盖安装，原球队选择和比赛战绩保留。两台模拟器的已安装 APK 与候选摘要一致。证据位于 `output/validation/1.0.2/`。
- 签名候选 `output/releases/android/1.0.2/BaseballMaster-Android-1.0.2-build13.apk`，SHA-256 `eabbaec337e77471d4e910a9652b2931d2a488f8824abc638913348412b4733a`，与官网 1.0.1 使用同一签名证书。合并与官网发布待安排。
