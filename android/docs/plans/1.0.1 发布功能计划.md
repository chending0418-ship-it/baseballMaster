# 棒球比赛记录大师 Android 1.0.1 发布功能计划

2026-11-10。Android 1.0.1（Build 12）修复官网 1.0.0 用户反馈的首球语音入口、确认流程、截图及计时问题。使用模拟器验收。[PR #60](https://github.com/chending0418-ship-it/baseballMaster/pull/60)。

- 正式比赛在第 0 球显示麦克风。先确认先发阵容，确认记入首球时才写记录并开始计时。练习也显示麦克风，可完整体验录音、建议与确认。练习状态只在当前练习局生效。
- 录音完成后自动分析。明确的坏球、看振、挥空或界外单球口令在手机上形成建议，其他情况交由混元解析。建议清楚时由记录员确认。解析不明确时保留转写，可编辑后重试，也可在同页选定单球判定再确认。Pro 需要补资料时进入原球场编辑。
- 语音转写及建议页允许截图。输入一次性开启码的弹窗保留保护。
- 正式比赛比分卡在赛前就显示计时。局数赛显示已用时间，时间赛默认显示剩余时间。开赛按钮可独立启动计时，保留 0 球。
- APK 沿用 1.0.0 包名及证书。模拟器验证官网 Build 11 覆盖升级，候选分发及应用市场状态按回执记录。官网公开分发前，需同步中英文隐私说明中的 Android 自动分析行为。

## 签名候选与验收

- Build 12 签名 APK 为 `output/releases/android/1.0.1/BaseballMaster-Android-1.0.1-build12.apk`，SHA-256 `2bc23be620da4583f36ac34b19b845d0302c8a052a1d17c8d26940b851457634`。Android 12 起可安装，Release 不可调试，证书与官网 1.0.0 相同。
- API 37 模拟器在同一签名包上通过 10 项语音及计时检查。包含正式首球、练习入口与练习确认只改内存局面、录完自动建议、重复结果的同页选择、编辑转写、一次确认、语音结果允许截图、两类赛制计时及兑换撤权。音频与混元回复使用测试输入，实况录音链路不在本次结果内。
- API 31 模拟器从官网下载包 1.0.0（Build 11）的同一文件覆盖安装至 Build 12，新进程读回测试球队选择及原比赛战绩。两台模拟器的安装包哈希均与签名候选一致。日志在 `output/validation/1.0.1/`。
- 官网下载及中英文隐私说明的改动已在品牌工作区本地暂存并校验。PR #60 待合并，官网和应用市场仍待本版发布。
