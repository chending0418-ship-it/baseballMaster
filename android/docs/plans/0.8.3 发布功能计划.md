## 共享球队统计

- [x] 统计页列出当前已加入的共享球队，只加入球队的成员也能进入。正式共享成绩与本机成绩使用独立范围，使用共享名册在本机记下的比赛仍可单独统计。
- [x] 读取已有球队名册、比赛列表和比赛详情。按云端场次 ID 和最新修订汇总已结束的本队比赛。进行中、预告、观赛、删除及未同步的本机草稿不纳入共享汇总。按正式球员对应计算打击、投手、守备和击球落点，保留历史参赛球员。继续以原始逐球记录显示单场详情。
- [x] 年度、模式和比赛筛选、球员及 PDF 使用同一份比赛集合。同步不完整或部分比赛暂无法读取时标示来源与状态。

## 官网更新提示

- [x] 首页进入前台时异步检查官网产品页的 Android 下载入口，按 APK 的 Build 比较。检测到更高 Build 才提示，用户可忽略本次 Build。「我的 → 关于 BaseballMaster」支持手动检查。
- [x] 从提示打开 [官网下载区](https://baseballmaster.cc/scorekeeper#download)，使用浏览器和系统安装流程。官网发布时先上传签名 APK，再把两个下载按钮都切换至同一个版本化路径 `/assets/android/<版本>-build<编号>/BaseballMaster-Android-<版本>-build<编号>.apk`。入口缺失、格式无效或两处版本不一致时客户端提示暂时无法检查。
- [ ] 发布后用旧的、已支持更新检查的版本核对实际更新提示以及完整下载安装过程。0.8.2 本身没有该提示，现有用户首次升级需从官网下载。

## PDF 文件名与共享比赛打席

- [x] 生成的 PDF 按报告类型命名，例如 `BaseballMaster-单打席详细版.pdf`。每次生成的文件存在独立的缓存目录，可重复导出或分享。
- [x] 共享比赛历史按原顺序显示打席序号。打者使用当场档案保存的姓名和背号，旧档案缺少打者资料时显示「历史球员」。记分事件引用可识别的打席时也显示序号。
- [x] 五个历史分类集中在同一组切换控件，常用手机宽度下同排显示，较大字体时自动换行。
