# OBS 转播叠加

在 OBS 的「来源」里添加三个独立的「浏览器」源。每个源填对应的 URL 和固定尺寸，分别拖到场景所需位置。画面外缘透明，组件尺寸不随球员姓名、球队或比赛内容变化。

| 浏览器源 | URL 的查询部分 | 宽 × 高 | 建议摆放 |
| --- | --- | --- | --- |
| 比分＋投手 | `?view=score` | 640 × 116 | 左上，投手紧接在比分板右侧 |
| 当前打者 | `?view=batter` | 600 × 108 | 左下 |
| 主客队阵容 | `?view=lineup&team=both` | 896 × 540 | 客队在左、主队在右，同一来源同步更新 |

单队阵容使用 `team=away` 或 `team=home`，尺寸为 440 × 540。普通浏览器可在观看码前加 `&preview=1`，让并排阵容适应较窄的窗口。

阵容沿用直播提供的打序和守位。超过 11 行时可以用 `&page=2` 选第二页。比赛进行中显示当前阵容，赛前显示先发阵容。

## 本地试用

从本工作树根目录启动内存直播服务：

```sh
PORT=18188 LIVE_DB=:memory: node live/server.mjs
```

另开一个终端，在同一目录发布合成比赛并打印三个可直接粘贴的 OBS URL：

```sh
LIVE_BASE=http://127.0.0.1:18188/livestreaming/novideo node live/demo.mjs --overlay
```

输入 `ball` 记一颗好球，`batter` 模拟一垒安打并切换下一位打者，`pitcher` 换投，`undo` 撤销上一步。约五秒内可看到变化。输入 `quit` 关闭示例直播，OBS 里的叠加层随即在下一次刷新时消失。

## 连接现有直播

叠加页与直播读取接口使用同一域名。从观赛链接取出观看码，组成对应的浏览器源 URL。

- 临时直播 `/livestreaming/novideo/<观看码>` 对应 `/livestreaming/novideo/overlay?view=score#temporary/<观看码>`。
- 共享球队直播 `/watch/#live/<观看码>` 对应 `/livestreaming/novideo/overlay?view=score#shared/<观看码>`。

把 `view` 改为 `batter` 或 `lineup` 即可分开添加。观看码放在 URL 的片段中。浏览器源以现有观看码读取直播，沿用原直播的开启、关闭和到期规则。每个源独立轮询，可能在同一轮内前后刷新。比分和投手始终一起按同一份修订更新。

打者展示本场安打、打数及最近三次已完成且可识别的打席。共享球队直播在已提供投手数据时展示好球数和三振数，旧临时直播按现有字段显示用球数。教练投球模式显示本打席用球数。终场保留比分，隐藏当前打者。直播关闭或过期后，对应源清空。网络中断时保留最近一次成功读取的画面最多二十秒。
