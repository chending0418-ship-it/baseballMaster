# 本机输出文件

这是棒球比赛记录大师自己的生成目录。资料位置和保存规则统一见 [工作区总导航](../../../management/AGENT-GUIDE.md)，当前发布版本与交接入口见 [CURRENT.md](../docs/CURRENT.md)。

- 从 CURRENT 选定实际发布版本，再查找对应交付材料；本文件不维护另一份“当前版本”。
- releases/ 按版本保存交付包、截图和归档；validation/ 保存验收与原始日志；marketing/ 保存产品宣传导出。
- samples/ 保存演示与设计输出；cache/ 保存可重建缓存；backups/ 保存历史备份；deployments/ 保存按用途分类的部署包。
- 公共品牌导出只放工作区 local/output/marketing/brand/，本目录中的同内容重复副本已核验后清理。
- 可编辑现行源稿放受 Git 管理的 docs/design/、scripts/ 和 templates/；历史编辑源稿见 docs/archive/output-sources/ 的清单。交付包内的 source 是当时的输出副本。
- 不在本目录根层散放文件。不要将归档、失败测试证据和私有素材当作普通缓存删除；不因本地存在包而宣称已上传或发布。
