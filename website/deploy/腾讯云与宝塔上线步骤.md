# baseballmaster.cc 官网配置

**2026-09-28 状态：根域名解析、独立官网和 SSL 证书已上线。** 此文保留从零配置参考，不要重复新建现有站点。本次使用 SSH 配置 Nginx，尚未导入宝塔网站列表；实际路径、证书有效期和后续维护见 [上线记录](2026-09-28-https-deployment.md)。

## 1. 腾讯云 DNSPod

进入 `baseballmaster.cc` 的解析记录，添加：

| 字段 | 填写内容 |
| --- | --- |
| 主机记录 | `@` |
| 记录类型 | `A` |
| 线路类型 | 默认 |
| 记录值 | `124.156.173.204` |
| TTL | 600 秒，或控制台默认值 |

该 IP 是本次用户指定的现有服务器地址，也与 2026-09-28 查询到的旧站点 A 记录一致。更换服务器时，以服务器控制台的新公网 IP 为准。记录值只填 IP，不加 `https://`、端口或路径。

`@` 对应 `baseballmaster.cc`，不是 `www.baseballmaster.cc`。本方案先只配置根域名；若后续需要 `www`，需同步补齐解析、站点绑定和证书覆盖。

保存 DNS 记录只会将访问指向服务器；还需完成独立站点配置，访问者才能看到官网。不要把新域名作为旧站点的别名绑定，也不要使用转发到旧域名的记录。

参考：[腾讯云 A 记录说明](https://cloud.tencent.com/document/api/302/3449)。

## 2. 宝塔独立站点

1. 打开宝塔“网站”，添加静态站点。
2. 域名填写 `baseballmaster.cc`。
3. 网站目录填写 `/www/wwwroot/baseballmaster.cc`，使用独立目录；不共享旧站点目录。
4. 不创建数据库，不启用 PHP。官网由静态文件组成。
5. 上传 `baseballmaster-home.zip`，解压后确保 `index.html`、`privacy.html`、`support.html` 和 `assets` 直接位于网站目录下。检查首页不会被宝塔默认欢迎页覆盖。

只上传这个静态包，不上传项目源码、TODO、验证记录或部署说明。

## 3. HTTPS 与路由

1. 解析生效、域名审核完成后，为 `baseballmaster.cc` 申请并安装证书，配置自动续期与 HTTP → HTTPS 跳转。
2. 备份新站点 Nginx 配置，在 HTTPS `server` 内合并本目录的 `nginx-homepage.conf`，保留证书与证书验证规则。已有同名 `location` 时替换，不能重复粘贴。
3. 根目录必须对应 `/www/wwwroot/baseballmaster.cc`。未知路径返回 404，资源目录不提供文件列表。
4. 执行 `nginx -t`，通过后再重载；有错误时先修正，不覆盖旧站点配置。
