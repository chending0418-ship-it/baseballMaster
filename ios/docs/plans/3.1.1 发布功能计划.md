## 本版功能

| 功能 | 本分支交付与边界 |
| --- | --- |
| 可配置开屏 | 固定 BM／App 图标，后台配置背景及文案；保留缓存、断网及素材校验兜底、跳过与导航。现行接口、配置和素材边界见 [可配置开屏](../../../docs/releases/3.1.1/CONFIGURABLE-LAUNCH.md) |
| 统一本机建赛与保存（I311-01／02） | 全部从首页创建、设置、开始及继续同一种本机比赛；本机保留完整原件，进行中沿用原本机文字直播，共享名单与赛后上传目标分开保存 |
| 独立赛后确认上传（I311-03） | 结束先保存，再选择上传球队或仅本机保留；固定操作 ID、冻结请求快照、持久重试及修订／权限校验，确认前不生成球队正式档案 |
| 统计归属（I311-04） | 未上传完赛在本机可查；球队统计只计成功上传档案，逐场、筛选与 PDF 使用一致范围，同源副本去重 |
| 旧请求隔离与兼容（I311-05 的已实现部分） | 保留旧请求及未确认草稿，不自动重放旧进行中写入；真实两场旧记录恢复与用户核对闭环仍未完成 |
| Pro 完整结果（I311-07–09） | “其他结果／全部结果”进入完整目录；本垒打、牺牲打等沿用垒况、球型、出局数和慢垒规则校验；取消不记球、确认仅一次及撤销恢复有关键回归 |
| 完赛返回与上传弹层 | 现场页及结果页按同一场比赛／本次终场只自动提示一次；返回比赛首页可用，手动上传入口保留 |
| 统一球场与历史落点 | 现场、Pro 防守、本场／年度图复用球场与守位布局；新点选逆映射保存，历史归一化落点不改写 |
| 直播文案 | 隐藏“点选去向／点选落点”操作提示，保留球型、区域、守备及逐球信息；网页已按另行授权部署，观众刷新原链接生效 |

## 平台目录与计划维护

本计划对应 **iOS**；当前 iOS 工作目录为 `apps/baseball-scorekeeper/`。Android 在并列的 `apps/baseball-scorekeeper-android/`，按其自身版本维护 `docs/plans/<版本> 发布功能计划.md`，不能将 Android 0.8.x 的功能或发布状态写入本 iOS 版本。两端每个版本都须维护发布功能计划，交付前更新范围、验证、遗留归属、构建与发布阶段，并从各自 `docs/CURRENT.md` 导航；开发日志和交付清单作为证据，不替代计划。此次补充只记录平台目录与维护规则，不改变上文功能／验收／商店状态，也不重新打包。
