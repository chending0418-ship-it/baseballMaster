# iOS 比赛分析

更新：2026-11-16。归入版本待定。iOS 与球队服务的评审分支为 `codex/ios/game-analysis`，基于 `main` 的 `8b33843`。

- 完赛结果的「比赛分析」入口覆盖已保存的单场。统计页按选定球队、年度、比赛模式和勾选场次生成全年或筛选报告。范围与统计页的数据口径一致。
- 报告包含比赛综述、关键局面或走势、各参赛球员评价和 MVP。单场可以评出双方参赛球员中的 MVP，全年及筛选分析只从本队评选。数据不足时可保留空选结果。可从报告页分享纯文字。
- 报告页固定显示比分或比赛范围，可切换「比赛报告」与「球员评价」。报告先展示 MVP 和评选依据，接着是综述和逐条关键局面或走势。单场球员评价按主客队分组，分享文字沿用报告顺序。生成提示要求短综述、每条局面聚焦一个赛况，并区分比赛已结束与比赛过程缺失。
- 请求包含所有所选比赛的逐局比分、R/H/E、赛制、部分关键局面和球员统计。单场最多取 18 条关键事件，汇总最多取每场 3 条。旧记录缺失比赛过程时，报告依据已有比赛和统计信息。
- 点击生成前告知数据用途和处理方。请求只包含结构化比赛资料与临时球员代号，报告在 App 内恢复姓名和背号。备份、比赛备注、队名、姓名、内部 UUID 及媒体均不进入生成请求。
- App 使用球队服务的设备授权。服务端异步请求 V-API，用短请求轮询结果，避免占用长时间的代理连接。分析临时保存在服务进程内，完成约 10 分钟后清理。服务不落盘报告、请求正文或供应商凭据。
- 服务器接受最多 1,000 场和 200 名参赛球员，解压后的请求上限为 256 KiB。超过上限时提示缩小范围。每日默认限每台设备 5 次，服务共 60 次，单设备最多一个运行中的分析。

### 服务配置与阶段

使用同一套 Learning Center 已有的 V-API 协议。默认地址为 `https://api.vveai.com/v1`，请求 `/chat/completions`，默认模型 `gpt-5.6-luna`。在记录大师球队服务的私有部署环境中设置 `BM_GAME_ANALYSIS_VPAI_KEY`。可选环境变量为 `BM_GAME_ANALYSIS_VPAI_URL`、`BM_GAME_ANALYSIS_VPAI_MODEL` 和 `BM_GAME_ANALYSIS_DAILY_LIMIT`。缺少有效配置时功能服务关闭。

2026-11-16 使用 Learning Center 本机配置和两名虚构球员发出接口验证，V-API 返回 HTTP 401。随后使用用户提供的新凭据在本机球队服务联调，`BM_GAME_ANALYSIS_VPAI_URL` 指向 `https://api.gpt.ge/v1`，`BM_GAME_ANALYSIS_VPAI_MODEL` 为 `gpt-6.1-sol`。新接口返回 HTTP 200，结构校验通过。生产部署、公开隐私说明更新及商店发布待安排。

### 本机验收

- iPhone 17 Pro 模拟器使用新 V-API 配置生成海浪 1–0 飞鹰的合成单场报告，核对综述、关键局面、18 名球员评价、暂定 MVP 与分享入口。样例在第 1 局上半局提前结束并含一条待确认的击球，报告仅按已确认记录暂选 MVP。同步截取全年及筛选场次入口。截图与测试回执在 `output/validation/game-analysis/provider-demo/`。

- 报告改版用同一场海浪 1–0 飞鹰合成赛再次调用 `gpt-6.1-sol`。iPhone 核对首屏比分、MVP、综述与关键局面并切换到球员评价。iPad 使用深色和辅助字号核对报告阅读及菜单切换。截图与回执在 `output/validation/game-analysis/report-layout/`。
- iPhone 与 iPad 模拟器分别从比赛结果和球队统计生成 1 场单场、3 场全年及筛选后 2 场的分析。截图核对综述、关键局面、MVP、球员姓名和分享入口。iPad 上修复了场次筛选行空白处的点击响应后通过复测。
- 两项原生输入测试核对完赛与筛选口径、逐局局面、TB、球员代号和姓名留在本机。直播及球队服务共 132 项测试通过，其中包含分析权限、重复请求、结果校验和配额。布局检查 18/18。
- 本地回执位于本工作树 `output/validation/game-analysis/`。本机 UI 联调可用 `node collaboration/test/game-analysis-ui-fixture.mjs` 启动模拟上游，然后运行 `BaseballMasterUITests/testGameAnalysisGeneratesFromSingleYearAndFilteredResults`。模拟服务只监听回环地址。
