# 3.1.4 送审前的隐私核对

2026-11-26，中英文公开隐私页及支持页均可访问。隐私页已有 iOS 语音记分、球队赛程、共享比赛和在线比赛分析的说明。球队赛程段落主要讲对阵、时间、场地和发布人。本版还通过球队服务处理赛中岗位、阵容变更和局面交接，建议维护者在中英文球队赛程段落补入以下文字。

**简体中文**　管理员在已发布的球队赛程中指派记录员时，球队服务保存本场岗位与对应的成员标识，供队内查看分工并核对写入权限。双人记录时，两台设备通过球队服务同步双方先发、球员姓名与背号、当场替补、换人、当前局面和处理结果。临时登记的队员仅进入本场名单。赛中改派局面记录员时，交接会将已保存的完整比赛记录传给接手设备。

**English**　When an administrator assigns scorers to a published team game, the team service stores each game role and the corresponding member identifier so team members can see assignments and the service can check write access. During two-device scoring, the service synchronizes starting lineups, player names and jersey numbers, game substitutes, substitutions, the current game situation and the outcome of lineup changes. Temporary players are added only to that game's roster. If a new play-by-play scorer takes over, the handoff transfers the saved game record to the receiving device.

**App Store Connect**　核对已申报的姓名、用户内容、用户及设备标识、产品交互是否覆盖上述用途，以及录音、转写和可选在线分析的实际处理。以上是对照构建的补充稿，公开政策和隐私问卷以账户持有人的现行申报为准。
