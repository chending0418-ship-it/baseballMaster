# 记录大师 iOS 3.1.4 双机试测指南

请在两台设备的 TestFlight 安装同一个 3.1.4 构建，用一场专门的测试赛程完成以下操作。两台设备可以使用同一个 TestFlight 测试账户，比赛岗位按 App 内的球队成员身份区分。两台设备分别使用同队的两个成员身份，两人都需要管理员或球队记录员资格。请勿把两台设备配对成同一位成员。

## 开赛与分工

1. 由管理员安排并发布球队赛程。尚未指派时，由创建比赛的管理员记录，另一名成员只能查看。只指派一人时，该成员负责整场。可分别用两场测试赛程核对这两种情况。
2. 在双人测试场的「本场记录岗位 → 安排记录员」将设备 A 的成员设为局面记录员，将设备 B 的成员设为阵容记录员。
3. B 在「本场记录岗位」点「在此设备管理阵容」，核对双方的先发并提交。A 从同一场赛程进入记分，核对首棒和先发投手后开始。A 记一球，B 继续管理阵容。

## 赛中补员及换人

1. A 先记一次保送，让进攻方有一名跑者在一垒。
2. B 打开进攻方的「管理阵容」，在替补区点「添加本场队员」。优先试一名已在球队名册、本场漏选的队员，再试临时登记一名 00 号队员。
3. B 保存调整后，让 A 保持联网并打开本场记分页。「待局面端处理」表示已经提交，普通补员会自动同步。B 看到「上次阵容调整已生效」后，核对新增队员在替补席。
4. B 将 00 号换上代跑。A 确认一垒跑者已切换，再记录他得分。核对比分、逐球记录和球员得分；未上场的替补不应得到这次得分，临时队员只进入本场名单。

## 两项容易出错的配合

- **换投碰到下一球。** B 准备换投时让 A 再记一球，然后 B 提交。若 A 收到「核对换人生效位置」，按现场情况选择从当前局面起生效，或退回 B 重选。核对已经投出的一球归原投手。
- **中途改派。** 管理员把局面岗位改给另一人。原局面设备联网，在「本场记录岗位」交接已保存的完整比赛记录。接手设备核对局数、比分、垒位和之前的逐球记录后，再记下一球。

## 守备球场可单机测试

进入练习局的 Pro 版，选择「击球进入场内 → 滚地出局」，点选地滚球落点，依次点三垒手、一垒手。查看箭头和「5 → 3」顺序，顺便试点投手和捕手，确认各标签容易区分、点选准确。
